LandTech Extras for Elementor — WordPress.org plugin directory assets
=====================================================================

These files are the SOURCE for icon/banner PNGs committed to plugin SVN at:
  https://plugins.svn.wordpress.org/landtech-extras-for-elementor/assets/

Do NOT use .plugin-check/.wordpress-org/ for deploy — that folder contains
Plugin Check tool placeholders (incorrect branding).

Deploy copies:
  icon.svg, banner.svg  → generated PNGs via scripts/deploy-wordpress-org-svn.sh
  screenshot-*.png      → copied as-is to SVN assets/

Required PNG outputs (generated on deploy):
  icon-128x128.png, icon-256x256.png
  banner-772x250.png, banner-1544x500.png
